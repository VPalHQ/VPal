VPal Server Command Center (beta)
=================================

VPal is a free control panel for a Palworld dedicated server on your own Windows PC.
VPal is an unofficial fan tool. It is not made by, affiliated with, endorsed by or
sponsored by Pocketpair, Inc. Palworld is a trademark of Pocketpair, Inc.

VPal is free software under the GNU General Public License v3.0. Its source code, and
every release, is at https://github.com/VPalHQ/VPal


What this setup puts on your PC
-------------------------------
Into the folder you pick (C:\VPal unless you change it):
  VPal.exe                      opens the control panel
  PalworldSettingsEditor.ps1    the control panel itself (PowerShell)
  CommandCenter\                the watchdog that runs in the background
  PalPlanner\                   the Pal Planner (the family pal website)
  NOTICE.txt                    this file
Shortcuts on the desktop and in the Start menu, and an entry in Apps (to uninstall).


What happens when you set up a server in the control panel
----------------------------------------------------------
  * SteamCMD, Valve's free server downloader, is downloaded from Valve into the
    steamcmd folder, and it downloads the free Palworld Dedicated Server from Steam
    (about 6 GB) into the same folder as VPal.
  * The server's settings file is written with your answers, and StartServer.bat is
    made. It checks for a Palworld update each time the server starts.
  * Windows asks once for administrator permission to add firewall rules for the game
    ports (UDP 8211, and UDP 27015 if the server is listed in Community Servers). You
    can say no; Windows then asks the first time the server starts.
  * If Python is missing, Python 3.12 is installed for your Windows account with
    winget (Microsoft's app installer). The watchdog and the Pal Planner need it.
  * The watchdog starts, plus a scheduled task named "VPal Server Watchdog" that starts
    it when you sign in to Windows and checks every 5 minutes that it is running.


What only happens if you turn it on
-----------------------------------
  * Pal Planner sharing: installs Tailscale (free) and shares the Pal Planner through
    your Tailscale link, plus a scheduled task "Pal Planner refresh".
  * Discord bot: uses a bot you create on Discord's developer site. Slash commands come
    in through your Tailscale link and must carry Discord's signature.
  * Daily restarts, backups, the whitelist and the rest of the Watchdog tab settings.


Network
-------
  * The watchdog only listens on this PC (127.0.0.1, ports 18770 and 18771).
  * The Pal Planner's website only listens on this PC (127.0.0.1:18765). Tailscale
    shares it only if you set that up.
  * The server's REST API (port 8212) only answers on this PC. Never forward it on your
    router.
  * Once a day the watchdog asks VPal's GitHub page whether a newer VPal is out. Nothing
    about you or your server is sent. An update only installs when you click Update.


Uninstalling
------------
Apps > VPal Server Command Center > Uninstall (or Uninstall VPal in the Start menu)
removes VPal's own files, shortcuts and scheduled tasks. Your Palworld server, worlds,
backups and settings stay in the folder, so nothing is lost by accident. Delete the
folder yourself if you no longer need them.
